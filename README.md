# yt-playlists
A quiet, ad-free way to organise your favourite YouTube videos and playlists in your own collections
**[Try it on yt-playlists.com →](https://yt-playlists.com)**

<img width="2560" height="1565" alt="yt-playlists-hero" src="https://github.com/user-attachments/assets/6bd871e4-0606-4d42-aa0c-d0bf35bd3f14" />


## Why

I never quite found a YouTube tool that let me browse my saved
videos the way I wanted, so I built my own.

## How it works

- Paste one or more YouTube URLs to add them
- Organise videos into your own collections, drag and drop to sort
- Everything stays in your own browser. No account, no server,
  nothing is tracked or uploaded anywhere
- Videos still play on YouTube itself
- Export/import your list as a backup file anytime

## Running it yourself

It's a single self-contained `index.html` file. No build step, no
dependencies. Download it, open it in a browser, or host it
anywhere that serves static files.
